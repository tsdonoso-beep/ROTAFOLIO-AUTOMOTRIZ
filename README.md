# Foto-Grama

Aplicación de rendición de gastos con extracción automática de comprobantes mediante IA (Gemini).

## Funcionalidades
- Sube imágenes o PDFs de facturas, boletas, recibos y tickets
- Extracción automática de datos con Gemini (API key individual por usuario)
- Guardado de imágenes en Google Drive organizado por proyecto/centro/caja
- Tabla resumen con totales y enlaces a Drive

## Configuración
Ver `.env.local.example` para las variables de entorno necesarias.
